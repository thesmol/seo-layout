## Условия заданий

Ниже приведён полный текст соответствующих заданий из предоставленной постановки. Пути `addons/...` относятся к исходному учебному комплекту.

### Задание №1

```text
Разместить в окне браузера 5 блоков-прямоугольников, реализующих типовой шаблон 2-колоночного резинового сайта:
        1 блок - "шапка/хеадер", высота 150 точек, на всю ширину окна браузера;
        2 блок - "меню", располагается под "шапкой" на всю ширину окна браузера;
        3 блок - "контент", левая колонка, высота на меньше 400 точек, ширина - все доступное пространство кроме правой колонки;
        4 блок - "доп.информация", ширина 200 точек/20%, высота не менее 300точек, правая колонка;
        5 блок - "подвал/футер", высота 100 точек, на всю ширину окна браузера.

    Решение должно адаптироваться к изменению ширины окна браузера. При выводе на печать должен печататься только блок "контент", на всю ширину страницы.

    Предпочтительно использовать flexbox css

    Добавить в "шапку" сложный логотип (выбрать самостоятельно или запросить у преподавателя); добавить пункты меню; добавить в контентную колонку осмысленный текст, соответствующий логотипу; привести код к seo-оптимизированному виду (семантические теги, заголовки title и h1, тег strong)
```
